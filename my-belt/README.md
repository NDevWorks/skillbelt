# Your skills go here

Put one skill folder in each belt folder:

```
my-belt/
├── white/<your-skill>/SKILL.md
├── yellow/<your-skill>/SKILL.md
├── green/<your-skill>/SKILL.md + references/
├── blue/csv-to-table/SKILL.md + scripts/
└── black/<your-skill>/SKILL.md + evals/ + scripts/ or references/
```

Start with [the White belt lesson](../belts/1-white.md), then run `npm run grade`.
